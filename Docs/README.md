# Sky Pilot — Flight Adventure

## Описание проекта
Sky Pilot — браузерная игра, в которой игрок управляет самолётом,
избегает препятствий и набирает очки.

## Технологии
- HTML5
- CSS3
- JavaScript

## Запуск игры
Открой файл index.html в браузере.

## Структура проекта
- index.html — структура игры
- style.css — оформление игры
- script.js — игровая логика
- Docs/README.md — описание проекта
- Docs/CONTROLS.md — управление игрой
